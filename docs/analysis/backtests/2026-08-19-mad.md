### 1.2 원문의 2단계 정의 (본문 246–300행)

```
MRAT_{j,t} = MA(21)_{j,t} / MA(200)_{j,t}                        … 식 (1)
σ_t        = 그달 MRAT 의 횡단면 표준편차
Top        = MRAT 십분위 최상 ∩ { MRAT >  1 + σ_t }
Bottom     = MRAT 십분위 최하 ∩ { MRAT <  1 − σ_t }
MAD        = +1 (Top) · −1 (Bottom) · 0 (그 외)
```

원문 표현 그대로:
`the long portfolio is a subset of top-decile stocks with MRAT values greater than
one plus a constant sigma, while the short portfolio consists of bottom-decile
stocks with MRAT values smaller than one minus sigma. We calculate sigma as the
monthly cross sectional standard deviation of MRAT.`

Table 3·4·Appendix C 캡션이 모두 같은 조건을 반복한다
(`provided that MRAT is greater than one plus` — 단일행 1회 · 정규화 2회).

**2σ 는 쓰지 않는다.** 원문은 2σ 를 "결과가 대체로 더 강해지지만 투자 가능
종목이 적은 달이 생긴다"고만 언급하고 본안에 쓰지 않는다.

## 4. 설계 명세 — 일봉 종가 기준 (PROTOCOL §4-(a) 항목 5)

1. **관측 시점** `t` = 역월 `m` 의 **마지막 거래일**(캐시에 봉이 있는 마지막 날).
   그달의 부분 월(캐시 마지막 역월)은 제외한다.
2. **MA(21)·MA(200)** = 시점 `t` 를 **포함한** 직전 21·200 거래일 **종가 단순평균**.
   **21·200 봉이 전부 유효할 때만 값을 낸다** — 부분 창을 평균하지 않는다.
   유효 = `close > 0`(KR 거래정지 봉은 `close` 만 직전가로 이월돼 있고 원문의 CRSP 도
   무거래일에 직전가를 남기므로, 이월 종가를 이동평균에 쓰는 것이 원문에 가장 가깝다).
3. **적격** = MRAT 유효 ∧ `t` 종가 ≥ 가격 하한(KR 1,000원 · US $5)
   ∧ (US) 직전 20봉 평균 거래대금 ≥ $2M **(PIT — look-ahead 금지)**.
4. **σ_t** = 3의 적격 종목 MRAT 의 횡단면 표준편차(ddof=1).
5. **다리** = §1.2 그대로. 어느 한쪽이 비면 그 달 제외(§3.5).
6. **체결** = `t` **종가**로 진입(원문은 월말 종가 기준). `t+1` 종가 체결은
   §7.4 견고성 축.
7. **보유** = 역월 `m+1` 의 마지막 거래일 종가까지 1개월. **동일가중.**
8. **비용** = 편도 요율 × `Σ|Δw|` (KR 0.14% · US 0.05% — PROTOCOL §2 왕복의 절반).
   직전 보유가 수익률로 표류한 뒤의 비중과 비교해 회전율을 잰다.
9. **재정렬** = 매월 5~8 반복.

**레짐 필터 없음** — 벤치마크 SMA200 은 보고용으로만 계산한다.

## 11. 확정된 오류와 재시도 출발점

### 11.1 고칠 것 — 게이트가 확정한 오류 (문서에 🔴 로 표시해 둠)

**N1 (치명) — §2.2-(3) 의 결론이 산술적으로 거짓이다.**

```
초안: "우리 표본은 ME Core 40% ~ Top 30% 에 대응하고, 그 칸의 VW 스프레드는
       1.73 → 0.82 로 무조건부 1.58 보다 낮다. 즉 1.58 은 낙관적 상단이다."
사실: 대응 칸 = {1.69, 1.73, 1.34, 0.82}.  1.69 와 1.73 은 1.58 보다 **크다.**
      같은 문장이 1.73 을 인쇄하면서 "1.58 보다 낮다"고 말한다.
정정: 대응 칸은 0.82 ~ 1.73 으로 **1.58 을 사이에 두고 갈린다.**
      1.58 은 보수적 하단도 낙관적 상단도 아니고 **범위 안**이다.
```

**1차와 2차가 같은 절에서 반대 방향으로 각각 틀렸다** — 이것이 종료의 직접 사유다.

**N2 — "범위 전체를 인쇄한다 · 고르지 않는다"가 거짓.**
§2.2 는 범위를 `0.82~1.73`(6칸)으로 선언하고 §6·`mad.py` 는 **ME Core 40%(1.69·1.73)를
빼고 4칸만** 인쇄한다. "고르지 않는 것이 이 설계의 핵심"이라 써 놓고 골랐다.
(누락 방향이 검정력을 낮추는 쪽이라 §3.1-8(다) 위반은 아니나 **자기진술이 사실과 다르다.**)

**N3 — "절반가량의 칸이 50% 미만이다"가 거짓.** 인쇄 5칸은
79.9 · 71.9 · 62.6 · 50.8 · 21.2 % → **50% 미만은 1칸(1/5)뿐**이다. §6·§8-14 두 곳.

**N4 — 검정력 범위가 틀렸다.** 선언한 `e*` 범위 기준 실제는 **21.2% ~ 87.7%**
(1.73 → 87.7% · 1.69 → 85.9%). 초안은 21.2~79.9% 로 적었다.
