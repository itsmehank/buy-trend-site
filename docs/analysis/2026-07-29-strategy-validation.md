# 매수 신호 전략 검증 — 설계부터 실행까지

작성 2026-07-29 · 대상 커밋 `df7326c` 기준 · 검증 범위 KR + US

---

## 1. 배경과 질문

`buy-signals.json`이 제시하는 8기간 성적표(승률·평균이익·평균손실·손익비·EV)는
"과거에 바로 이 자리에서 샀다면 어땠는가"를 근거로 제시한다. 이 문서는 그 근거가
실제로 성립하는지를 측정한 결과다.

세 가지를 물었다.

| # | 질문 |
|---|---|
| Q1 | 사이트가 뽑은 종목군이 시장(지수)을 이기는가? 이긴다면 **무엇이** 그 성과를 만드는가 |
| Q2 | 매도가 "n일 보유 후 청산"인 것이 성과 실패의 원인인가 (추세추종은 추세 이탈 시 청산해야 함) |
| Q3 | 왜 297종목 중 55%가 최적 보유기간으로 252일을 뽑는가 |

## 2. 검증 대상 — 사이트의 실제 포함 조건

코드를 읽어 확인한 결과, 화면에 종목이 실리는 조건은 **3개**다.

| # | 조건 | 코드 |
|---|---|---|
| 1 | RS ≥ 90 (모멘텀 백분위 상위 10%) | `build.py:138`, `config.RS_MIN` |
| 2 | 최적 보유기간이 잡히는 신호 존재 (표본 ≥ 20 & 손실 표본 존재) | `backtest.select_optimal` |
| 3 | 현재가가 매수 구간(zone) 안 | `zone.in_zone` |

**별점은 제외 기능이 없다.** `stars.stars_from_tags`(`stars.py:61`)는 주식에 대해 항상
1/2/3을 반환하고 `cut_reason`은 표시용이다. 따라서 별점은 정렬만 바꾸며, 시가총액
데이터 없이도 포함 조건을 재현할 수 있다 — 이것이 과거 시점 재현을 가능하게 했다.

### 파이프라인 구조 (오해 방지)

배치는 **전체 유니버스를 매일 적재하고, 그 전체에서 RS를 계산한 뒤, 상위 10%만
백테스트**한다. 화면의 297종목은 수집 대상이 아니라 최종 출력이다.

```

        ↓  15년치 가격 다운로드 (증분 캐시)

        ↓  zone 통과분
화면 US 279 + KR 18
```

## 4. 방법

### Phase 1 — 기여 분해 (walk-forward)

과거 각 시점에서 **데이터를 그 시점까지 잘라** 사이트의 3개 조건을 재현하고,
이후 수익을 같은 창의 지수 수익과 비교한다.

파라미터: `STEP = 20`(월 1회) · `MIN_BARS = 500` · `RS_MIN = 90` ·
수평선 `[20, 60, 126, 252]`일. KR·US 동일.

4개 그룹을 비교해 **어느 필터가 성과를 만드는지** 분리한다.

| 그룹 | 정의 |
|---|---|
| **A** | 사이트 3개 조건 전부 (RS≥90 + 신호 + zone) |
| **B** | 적격 유니버스 전체에서 무작위 동수 추출 |
| **D** | **RS≥90 안에서** 무작위 동수 추출 |
| **E** | RS≥90 전체 |

- `D − B` = **RS 필터의 기여**
- `A − D` = **신호 + zone의 기여**

B가 아니라 D를 대조군으로 둔 것이 핵심이다. B만 쓰면 RS와 신호의 기여가 합쳐져
구분되지 않는다.

### Phase 2 — 매도 규칙 비교

진입을 고정하고 매도만 6종으로 교체한다. 진입 6종 × 매도 6종 = 36칸을 전부 보고한다.

| 매도 | 정의 |
|---|---|
| A | 252일 고정 (현행) |
| B | 20일 고정 |
| C | 트레일링 스톱 −15% (보유 중 고점 대비) |
| D | 종가가 SMA60 하회 |
| E | 종가가 SMA20을 5일 연속 하회 |
| F | 트레일링 스톱 −25% |

진입 6종: 이평 `L|SMA|20` · 박스 L(60일) · 박스 S(20일) · 신고가 ATH · 신고가 20일 ·
신고가 55일. 최대 추적 504일(무한 보유 방지).

거래비용은 **US 0.10%**(거래세 없음)와 **KR 0.28%**(거래세 0.15 + 수수료 0.03 +
슬리피지 0.10) 둘 다 표기해 민감도를 노출한다.

### Phase 3 — EV 상승 원인 분해

같은 진입에 대해 (a) 원시 수익 (b) 지수 차감 초과 수익 (c) **신호와 무관한 무작위
날짜**(엣지 0 대조군)로 각각 EV를 계산한다. 추가로 합성 데이터(드리프트 0인 기하
무작위 보행)로 메커니즘을 독립 검증한다.

### 사전 판정 기준 (결과를 보기 전에 고정)

다중비교(36칸)에서 우연히 좋은 칸이 나오는 것을 막기 위해 실행 전에 정했다.

| 판정 | 조건 |
|---|---|
| 신호 기여 인정 | `A − D`가 **평균·중위 둘 다** 양수 + 여러 수평선에서 일관 |
| 매도 가설 지지 | D 또는 E가 A보다 **비용후 연율화 ↑ 그리고 중위 개선** + **여러 진입에서 일관** |

한 칸만 좋은 것은 우연으로 간주한다.

## 5. 발견한 버그와 수정

검토 과정에서 자체 스크립트의 버그 2건을 발견해 수정하고 재실행했다.

### ① E 규칙 벡터화 오류 (계산 오류)

전역 `rolling(5).sum() >= 5`로 "5일 연속 하회"를 구하면 **이벤트 이전에 시작된
연속을 이어받아** 1~4일에 조기 발동한다. 루프 버전과 시행당 25~88건 불일치.

수정: 전역 연속 카운트를 "이벤트 이후 경과일수"로 상한 처리
(`np.minimum(runlen[i+1:i+MAXH+1], DAYS)`). 8시행 **불일치 0건** 확인.

### ② 거래대금 필터 look-ahead (설계 오류)

`universe.dollar_vol_filter`는 `df.tail(20)` — 즉 **최종 봉 기준** 유동성을 쓴다.
이를 2013년 as-of 시점에 적용하면 "오늘 유동성 있는 종목"만 과거에 매수하는
look-ahead가 된다.

수정: 각 시점/이벤트 직전 20봉 평균 거래대금을 그 자리에서 계산해 적용.

### 수정이 결론에 미친 영향

| 지표 | 수정 전 | 수정 후 | 방향 |
|---|---|---|---|
| Phase 1 신호 기여 (평균) | −0.4 ~ −2.8%p | **−0.2 ~ −0.6%p** | 완화 |
| Phase 2 초과수익 (신고가20 A) | 4.4% | **1.7%** | 축소 |
| Phase 3 드리프트 기여 | 76% | **88%** | 강화 |

핵심 결론은 유지되고 Phase 3은 강화됐다.

손실 거래를 보면 **91%가 한때 플러스**였고 중위 **+10.7% → −21.3%**로 끝났다

그런데 손절을 넣어도 중위는 개선되지 않았고, 개선된 연율화의 상당 부분은
"추세 이탈 로직"이 아니라 단순히 **짧게 보유**한 효과였다. 매도 규칙은 분포의
모양(분산·치우침·보유기간)을 바꾸지만 **기댓값을 만들어내지 못한다.**

### Phase 3 — 252일 편중의 원인은 EV 공식의 구조

EV 공식을 정리하면 **정확한 항등식**이 나온다 (10만 표본으로 소수 10자리까지 검증).

```
EV = (p·평균이익 + (1−p)·평균손실) / |평균손실|  =  E[수익] / |평균손실|
```

| 항 | 보유기간에 따른 성장 |
|---|---|
| `E[수익]` (분자) | 기간에 **비례** (일간 평균의 누적) |
| `\|평균손실\|` (분모) | 기간의 **제곱근** (변동성 스케일) |

→ **평균수익이 조금이라도 양수면 EV가 √기간으로 부풀려진다.**

합성 데이터(시장·종목·신호 없는 순수 난수)로 독립 검증:

| 일간 평균수익 | 2일 EV | 252일 EV | 배율 |
|---|---|---|---|
| 정확히 0 | 0.001 | 0.000 | **1.0배 (평평)** |
| +0.04% | 0.038 | 0.540 | **14.2배** |

**US 실측** (표본 450,911건, 이평 L/S SMA20)

| 보유 | 원시 EV | 초과 EV (지수 차감) | 초과 승률 | **무작위 날짜 EV** |
|---|---|---|---|---|
| 2일 | 0.052 | 0.009 | 49.2% | 0.015 |
| 60일 | 0.282 | 0.041 | 47.8% | 0.076 |
| **252일** | **0.662** | **0.077** | **45.6%** | **0.169** |

- 드리프트가 원시 EV의 **88%**를 설명한다 (KR 72%)
- 남은 0.077은 **무작위 날짜 0.169의 절반도 안 된다**
- 초과 승률은 모든 기간에서 **46~49%** — 어떤 보유기간도 지수를 절반 이상 이기지 못한다

**즉 EV는 서로 다른 보유기간끼리 비교하면 안 되는 지표다.** 8기간 중 EV 최대를
고르는 규칙은 구조적으로 가장 긴 기간을 뽑는다.

## 7. 결론

| 질문 | 답 |
|---|---|
| **Q1** 성과의 출처 | **RS ≥ 90 하나.** 신호(이평·박스·신고가)와 매수 구간의 기여는 KR·US 양쪽에서 0 또는 음수 |
| **Q2** 매도 규칙이 실패 원인인가 | **아니다.** 진단(구조 불일치·손절 부재)은 정확했으나, 고쳐도 중위는 개선되지 않고 개선분은 "짧은 보유" 효과 |
| **Q3** 252일 편중의 원인 | **EV 공식이 `E[수익]/√변동성` 구조라 양수 평균수익이 √기간으로 증폭된다.** 그 평균수익의 88%는 시장 드리프트, 나머지는 생존편향 |

### 실용적 함의

- **성적표 숫자(승률·EV·최적 보유기간)를 매매 근거로 쓸 수 없다.** 이것은 수학적
  결론이므로 시장과 무관하다.
- 사이트가 실제로 제공하는 검증된 가치는 **"모멘텀 상위 10% 종목 목록"** 하나다.
- 다만 EV 공식·`min_sample`·최적기간 선정 규칙은 명세서 ✅(원본 사이트에서 검증된
  사실)이므로 **바꿀 수 없다.** 그래서 커밋 `df7326c`은 규칙을 고치는 대신
  "이 숫자를 얼마나 믿을 수 있는지"(백테스트 구간 · 독립 표본수 · 신뢰구간)를
  화면에 노출하는 방향으로 대응했다.

## 9. 부수 발견 — 종가 0/NaN이 만드는 4개 결함 (**수정 적용됨**)

검증 중 종가가 0인 종목을 만나 드러났다. 실제 존재: **CBIO**(2014-01~2022-09,
2,189행), **DEC**(2021-01~2023-11, 691행). 처음에는 배치 중단 하나로 보였으나
확인해보니 경로가 **4개**였고, 그중 셋은 **크래시 없이 조용히 결과를 왜곡**한다.

| # | 경로 | 트리거 | 증상 | 심각도 |
|---|---|---|---|---|
| ① | `rs_raw` → **NaN** | 최종 종가가 NaN | `rs_percentiles`의 `int(round(NaN))`에서 `ValueError` → **배치 전체 실패** | 높음 |
| ② | `rs_raw` → **inf** | 룩백 시점 종가 0 | **크래시 없음.** `rank` 최상위가 되어 그 종목이 **RS=100**으로 상위 10%에 무조건 진입 | **높음 (조용함)** |
| ③ | `volatility_60d` → NaN | 60일 창에 종가 0 | `vol_q4_cut = np.quantile(...)`이 NaN → `vol >= NaN`이 항상 False → **`TAG_VOL_Q4`가 전 종목에서 소멸**, 별점이 실제보다 후해짐 | 중간 |
| ④ | `surge_flags` → inf | 20일 전 종가 0 | `inf >= 0.5` → **급등으로 오판** → 대형주면 별 1개로 강등 | 중간 |

### 적용한 수정

소비처가 아니라 **원천**에서 막았다. 각 계산 함수가 비유한값이면 `None`/`False`를
돌려주고, 호출부는 이미 그 값을 처리하고 있다.

| 파일 | 변경 |
|---|---|
| `pipeline/rs.py` | `rs_raw` — 결과가 비유한값이면 `None` (①②) |
| `pipeline/stars.py` | `volatility_60d` — 비유한값이면 `None` (③) · `surge_flags` — 비유한 수익률은 판정 제외 (④) |
| `pipeline/build.py` | RS 계산 불가 종목을 **`log.warning`으로 노출** — 조용한 제외는 재발을 못 보게 한다 |
| `tests/test_core.py` | 4개 경로 재현 + `rs_percentiles` 생존 회귀 테스트 7개 |

### 검증

| 항목 | 결과 |
|---|---|
| 명세서 영향 | 없음. RS 산식은 `[자체 기준] 1`(❓ 층)이고 이는 산식 변경이 아니라 **정의역 방어**. EV 공식·`min_sample`·최적기간 선정 같은 ✅ 항목은 무관 |
| **현재 출력 변화** | **없음.** 라이브 데이터 실측 — KR 646종목 중 **0건**, US 3,319종목 중 **0건**이 비유한값을 낸다 |
| 통합 동작 | 종가 0인 합성 종목을 넣어 `build_market` 실행 → 경고 1줄 출력, **크래시 없음**, 해당 종목이 결과에서 제외됨 |
| `RuntimeWarning` | 억제하지 않았다. 종가 0은 데이터 이상 신호이므로 로그에 남는 편이 낫다 (테스트에서만 `np.errstate`로 국소 억제) |
