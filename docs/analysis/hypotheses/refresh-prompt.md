한국·미국 주식 롱온리 백테스트에 쓸 **규칙 기반 추세추종 전략**을 2~4개 제안해 주세요.
제 시스템은 20건 가까이 테스트하며 **무엇이 측정 가능한지**를 정밀하게 파악했습니다.
그 제약이 아래에 있고, 이걸 못 지키면 테스트 자체가 불가능합니다.

## 가장 중요한 제약 — 포트폴리오를 넓게 잡아주세요

제 시스템은 **"상위 20종목 중 몇 개를 다른 종목으로 바꾼다"** 형태로 4번 시도해
**4번 다 측정 불가**로 끝났습니다. 원인을 정량화했습니다.

```
필요한 관측 수 = (2.8 × 종목 간 수익 차이의 표준편차 ÷ 찾으려는 효과)²
```

- 개별 종목의 월수익 차이는 표준편차가 **23~30%p**입니다. 신호를 무엇으로 바꿔도
  이 값은 거의 변하지 않습니다(5종을 시험해 23.5~27.3 범위).
- 그래서 연 6%p 효과를 잡으려면 **16,000~28,000 종목-월**이 필요한데,
  20종목 중 5개 교체로는 11~14년 모아도 **385~705개**뿐입니다. **6~30배 부족**합니다.

**반면 유일하게 측정에 성공했던 설계는 300~400종목 포트폴리오에서 필터 하나를
껐다 켠 것**이었습니다. 차이 포트폴리오 자체가 분산돼 잡음이 1/10이었습니다.

**그래서 이렇게 제안해 주세요.**

| ✅ 이렇게 | ❌ 이렇게는 말고 |
|---|---|
| **최소 100종목, 가능하면 200~500종목** 보유 | 상위 10~30종목 집중 |
| 부품을 껐을 때 **종목 집합은 거의 그대로**이고 비중이나 편입 범위만 달라짐 | 부품을 껐다 켜면 종목이 통째로 바뀜 |
| 예: "전체 유니버스를 담되 조건 X인 종목만 제외한다" | 예: "상위 20종목 중 조건 X인 5개를 다른 종목으로 교체한다" |
| 예: "비중을 Y에 비례해 기울인다" (전 종목 유지) | 예: "Y 상위 종목만 골라 담는다" |

**부품을 끈 버전과 켠 버전이 종목의 90% 이상을 공유**해야 합니다.

## 두 번째 제약 — 절대 성과로 판단할 수 없습니다

제 시스템에서 **리밸런싱 날짜만 바꿔도** (규칙은 글자 하나 안 바꾸고) 한국 CAGR이
**3.67% ~ 13.08%로 갈립니다.** 즉 "이 전략이 연 몇 % 나왔다"는 그 자체로는 정보가
거의 없습니다.

**따라서 반드시 "부품 있음 vs 없음"의 짝지은 비교로 검증 가능한 형태**여야 합니다.
"이 전략이 지수보다 낫다" 형태의 주장은 검증할 수 없습니다.

## 데이터 제약 (이 밖의 데이터가 필요하면 제안 불가)

가진 것은 **이게 전부**입니다.

- **일봉 OHLCV**(시가·고가·저가·종가·거래량, 수정주가) — 한국 약 12년, 미국 약 15년
- **벤치마크 지수 종가** (^KS11, ^GSPC)
- 시가총액·섹터는 **현재 스냅샷만** 있고 과거 시점 값이 없음

제안 불가: 분봉·장중 데이터 / 재무제표·펀더멘털 / 상장폐지 종목 이력 /
공매도·수급·기관외국인 매매 / 뉴스·심리·검색량 / 옵션·선물 /
**과거 시점의** 시가총액·섹터 구성

가격·거래량·지수만으로 계산되는 것은 전부 가능합니다
(이평, 채널, 신고가, 변동성, 모멘텀, 거래량 비율, 상관계수, 회귀 등).

## 기타 조건

- 규칙이 단순하고 **일봉 종가 기준으로 모호함 없이** 기술될 것
- **시장이 강세일 때만 신규 매수** (지수 > 200일 이평 같은 레짐 필터)
- 롱온리 (공매도 불가)

## 이미 테스트했거나 종료된 것 — 구조가 같은 변형은 제외

1. RS 랭킹 + 신호 3종(이평 눌림·박스 돌파·신고가) + 매수 zone
2. 박스권 돌파 (20일/60일), 신고가 돌파 (20일/55일/사상 최고가)
3. 보유기간별 기대값(EV) 최대 선택 규칙
4. **Clenow 지수회귀 모멘텀** (90일 로그가격 회귀 기울기 × R², ATR 사이징)
5. **정보 이산성(FIP)** — 수익률 경로의 연속성으로 종목 선별
6. **잔차 모멘텀** (Blitz) — 시장 1팩터 회귀 잔차로 랭킹
7. **시계열 모멘텀 + 역변동성 가중 + 변동성 타깃** (Moskowitz / Barroso)
8. 청산 규칙 진단 (SMA100 하회 매도, 15% 갭 매도, 랭킹 이탈 매도)
9. **상관계수 상한** — 이미 담은 종목과 상관이 높으면 건너뛰기
10. **거래량 과열 기각** — 상대거래량이 높은 종목 편입 제외
11. **리밸런싱 시점 분산** (트랜치) — 이미 측정 완료

**특히 "모멘텀을 어떻게 측정할 것인가"라는 축은 4번 시도해 전부 실패했습니다.
그 축은 피해 주세요.**

아직 건드리지 않은 축의 예시(참고용):
넓은 유니버스에서의 제외 규칙 / 비중 배분 함수 / 레짐 판정 방식 자체 /
현금 비중의 연속적 조절 / 유니버스 정의(거래대금·주가 필터) 자체

## 답변 형식

전략마다 아래를 채워주세요.

1. **전략 이름**
2. **베이스라인** — 부품이 꺼진 상태. **몇 종목을 담는지 명시**
3. **부품 1개** — 무엇을 어떻게 바꾸는가 (검증 대상)
4. **매수 규칙** — 일봉 종가 기준, 판단 시점 명시
5. **매도 규칙** — 일봉 종가 기준
6. **부품을 껐을 때와의 종목 겹침 추정** — **90% 이상이어야 합니다**
7. **부품이 영향을 주는 자산 비중** — 포트폴리오의 몇 %인가
8. **근거** — 논문·서적 출처 (저자·제목·연도, **가능하면 결과 표의 수치까지**)

**8번의 수치 인용을 부탁드립니다.** 지난번에 "이 논문은 위험 감소를 주장한다"고
요약했다가 원문을 확인해 보니 수익 개선이 헤드라인이어서 테스트가 무효가 된 적이
있습니다.

투자 자문이 아니라 **백테스트 가능한 규칙으로 정리**해 달라는 요청입니다.
