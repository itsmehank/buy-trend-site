# backtest-refresh — 가설 풀 수혈

가설 풀이 고이지 않게 외부(web Claude 또는 직접 웹검색)에서 새 전략을 들여와
판정 후 등재한다. **시작 전에 반드시 읽는다:** `docs/analysis/PROTOCOL.md`,
`docs/analysis/hypotheses/registry.md`, `docs/analysis/hypotheses/jail.md`.

쓰기 허용 경로는 `docs/analysis/**` 만. push 금지(커밋도 사용자가 요청할 때만).

## 모드 판별

| 입력 | 모드 |
|---|---|
| 인자 없음 | **프롬프트 발급** |
| 전략 내용 붙여넣기 (web Claude 답변 등) | **판정** |
| `direct` | **직접 검색** — WebSearch로 후보를 직접 수집한 뒤 판정 모드와 동일 처리 |

## 프롬프트 발급 모드

web Claude에 복사해 넣을 프롬프트 1개를 코드블록으로 출력한다. 프롬프트에 반드시
포함할 것 (이걸 빼먹으면 중복·구현불가 답이 돌아와 재시도만 늘어난다):

1. **요구 조건**: 심플한 규칙 기반 / 추세추종 계열(듀얼 모멘텀·정기 리밸런싱·레짐
   분리 허용) / 시장 강세일 때만 매수 / 일봉 종가 기준으로 기술 가능할 것
2. **데이터 제약**: 일봉 OHLCV + 지수만 있음 (jail.md의 표를 요약해 넣기 —
   분봉·재무·수급·뉴스 불가)
3. **제외 목록**: registry의 테스트 완료·대기·후보 가설 키 전부 + jail 수감자 요지
   ("이것들과 구조가 같은 변형은 제외" 명시)
4. **답변 형식 지정**: 전략마다 이름 / 매수 규칙 / 매도 규칙 / 근거(출처) — 2~4개
5. registry `후보`에 재시도 중인 항목이 있으면 **최근 거절 사유**를 프롬프트에
   반영 ("직전 제안은 ~해서 반려됨" 문구)

출력 후: "답변을 받아오면 `/backtest-refresh`에 붙여넣어 달라"고 안내하고 종료.

## 판정 모드

붙여넣은 전략 각각에 대해 3단계 판정을 **순서대로** 수행하고 근거를 남긴다.

| # | 판정 | 기준 | 탈락 시 |
|---|---|---|---|
| ① | 구현 가능 | jail.md 수감 기준 (필요 데이터가 일봉 OHLCV+지수뿐인가) | **감옥 등재** (사유 기록) |
| ② | 중복 아님 | registry 전체와 구조 비교 (파라미터만 다르면 중복) | 반려 |
| ③ | 조건 부합 | 심플 / 추세추종 계열 / 강세장 한정 / 규칙이 모호하지 않음 | 반려 (내용 빈약 포함) |

전략이 여러 개면 **각각 독립 판정**한다 — 통과분은 그 자리에서 등재하고, 탈락분만
아래 재시도 절차를 밟는다.

- **통과** → registry `대기` 풀에 등재: 새 H-번호, 가설 키, 출처(수혈/URL), 등재일.
  `후보`에 있던 항목이면 그 행을 제거.
- **① 구현 불가** → 시도 카운트와 무관하게 **즉시 감옥 등재로 종결** (데이터가
  없는 건 재시도해도 달라지지 않는다).
- **②③ 반려** → 탈락 사유를 정리하고 registry `후보`의 시도 카운트를 갱신한다
  (없으면 `시도 1/3`로 새 행). **시도 3/3 소진이면 그 후보 라인은 폐기**(행 제거)
  하고 더 재발급하지 않는다.
- ②③ 반려가 있고 시도가 남았으면: 거절 사유를 반영한 **개선 프롬프트**를
  다시 발급(위 발급 모드 형식, 동일한 마무리 안내 포함)하고 종료.
- 판정을 마치면 결과 표(전략 / 판정 / 사유 / 등재 ID)를 출력한다.

시도 카운트는 세션 기억이 아니라 **registry `후보` 섹션의 기록이 기준**이다
(독립 세션에서도 이어지도록).

## 흔한 실수

- 프롬프트에 제외 목록을 안 넣기 → 같은 전략이 계속 돌아온다
- "박스 돌파의 기간만 다른 변형"을 새 가설로 등재 → 구조가 같으면 중복 (registry 상단 기준 참조)
- 등재하면서 사전 판정 기준까지 미리 쓰기 → 사전 기준은 `/backtest` 2단계에서 작성한다 (여기서는 가설 키만)
- 판정 없이 일괄 등재 → 반드시 전략별 ①②③ 근거를 남긴다
